Pour commencer

Trouvez des données. Combinez-les. Reportez-les sur une carte. Explorez-les. Exportez votre création et diffusez-la. Grâce à GEO.ca, trouvez les données qu’il vous faut et utilisez-les de la manière qui vous convient. Nos directives étape par étape ci-dessous vous aideront à commencer.

Accueil / Pour commencer

Sur cette page

  1. Trouver des données
  2. Consulter des données
  3. Créer une carte

Trouver des données

Commencez directement sur notre page d’accueil.

  • Utilisez la barre de recherche : À l’aide de la barre de recherche, faites des recherches dans toute la collection de données géoréférencées fédérales, provinciales et territoriales.
  • Parcourez les thèmes : Choisissez l’un de nos neuf thèmes pour rechercher des données et consulter les cartes, applications et ensembles de données vedettes.

Utiliser l’onglet « Découvrir »

  • Faites des recherches par thème, type de contenu ou organisation : En plus des thèmes, vous pouvez faire des recherches par type de contenu, comme les API, ou par organisation ayant publié des données.
  • Consultez les données de base : Trouvez les données de base qui décrivent l’eau, les terres et les infrastructures bâties au Canada – les fondements géographiques essentiels pour soutenir et contextualiser les données thématiques.

Recherche avancée

En utilisant la barre de recherche de la page d’accueil, vous accédez à la page de recherche avancée, où les résultats sont listés et où vous pouvez effectuer de nouvelles recherches.

  • Barre de recherche : Faites des recherches à l’aide de mots-clés, de titres d’ensembles de données ou d’identifiants uniques.
  • Sous-menu « Filtres » : Configurez un filtre avancé pour affiner les résultats de la recherche en fonction de catégories, d’organisations, de types, de l’étendue spatiale ou temporelle, etc. Ajoutez ou supprimez des filtres pour obtenir les résultats dont vous avez besoin.

Consulter des données

Voir les résultats

  • Flèche de déroulement : Cliquez sur la flèche pour obtenir un aperçu du résultat. L’aperçu comprend le titre de l’ensemble de données, une description, l’organisation qui publie les données, les formats de ressources de données disponibles et un aperçu de la carte, le cas échéant.
  • Favoris : Cliquez sur l’icône en forme de cœur pour ajouter l’ensemble de données à vos favoris et pouvoir y revenir après d’autres recherches.
  • Aperçu de la carte : Une carte interactive est disponible pour chaque résultat; il peut s’agir d’un aperçu des données ou d’un index des fichiers, selon le cas. Si la visualisation sous forme de carte n’est pas activée pour l’ensemble de données, l’aperçu montre l’étendue géographique de ce dernier.

Voir le dossier

Accédez au dossier complet de l’ensemble de données en cliquant sur le titre du résultat.

Accéder aux données

Sur la page du dossier, vous avez accès à une carte des données, le cas échéant, et à une liste de toutes les ressources de données associées à l’ensemble de données. Si vous cliquez sur une ressource, vous l’ouvrirez ou la téléchargerez dans le format indiqué.

  • Description et métadonnées : Le dossier commence par une description générale de l’ensemble de données. Vous pouvez ensuite ajouter le dossier à vos favoris et obtenir des métadonnées clés, telles que l’organisation qui publie les données et des renseignements sur la licence.
  • Consultez la carte : Explorez les données ou leur index, selon le cas, dans le visualiseur de cartes de GEO.ca, GeoView.
  • Accédez aux données : Sous la carte, le tableau des ressources de données fournit les liens permettant d’accéder aux données, aux documents de soutien ou aux services Web, ou de télécharger les données et les documents. Ouvrez les autres onglets en haut du tableau pour obtenir de l’information supplémentaire, soit les métadonnées avancées, les coordonnées de l’organisation qui publie les données, et des produits connexes.

Voir des dossiers similaires

Ce ne sont pas les données que vous cherchez? Au bas de la page de dossier de l’ensemble de données se trouve une liste de suggestions de dossiers similaires.

Créer une carte

Suivez ces étapes simples pour choisir et combiner des contenus afin de créer votre propre carte à analyser et à diffuser.

Voir votre carte

  1. Vous pouvez ajouter à vos favoris des ensembles de données figurant dans vos résultats de recherche en cliquant sur l’icône en forme de cœur située à côté de chaque résultat listé.
  2. Après avoir choisi vos ensembles de données, rendez-vous sur la page des favoris au moyen du menu de navigation supérieur.
  1. Dans la page « Favoris », cliquez sur le bouton « Voir sur la carte » situé sous le tableau pour accéder à une carte interactive montrant tous les ensembles de données placés dans vos favoris qui peuvent être visionnés.

Téléverser vos propres données

Ajoutez des données à votre carte! Vous pouvez ajouter des données provenant d’autres sources en les important à l’aide du sous-menu « Ajouter » situé sous l’onglet « Couches ». Vous pouvez ajouter des données ou des services en téléversant un fichier, en saisissant l’URL d’un service Web ou en ajoutant d’autres ensembles de données de GEO.ca à l’aide de leur identifiant unique.

Qu’est-ce que l’identifiant unique?

Chaque dossier d’ensemble de données possède son propre identifiant unique, qui se trouve dans le dernier segment de l’URL. Par exemple, l’identifiant unique de la Mosaïque du Modèle numérique d’élévation de haute résolution est 0fe65119-e96e-4a57-8bfe-9d9245fba06b.

Exporter votre carte

Pour exporter votre carte, utilisez la fonction « Exporter » située dans la barre latérale à gauche de l’affichage de carte. Cette fonction vous permet de télécharger votre carte.

Dites-nous ce que vous pensez!

GEO.ca s’engage à favoriser un dialogue ouvert et à renforcer la communauté autour des enjeux et sujets liées à la localisation qui vous intéressent.
